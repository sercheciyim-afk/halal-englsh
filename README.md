# Halal English

Интерактивная история о чтении и путешествиях.

Сайт: https://sercheciyim-afk.github.io/halal-englsh/

Статический сайт для GitHub Pages (main, / root). Все изображения WebP и шрифты хранятся здесь, внешние CDN не нужны. Экран загрузки с фонариком ждёт изображения и шрифты. Поддерживаются клавиатура и reduced motion.

Исходники — в source.zip. Для пересборки: npm install, npm run build. Содержимое github-pages загрузить в корень репозитория.

Квиз даёт только приблизительный ориентир, не является полноценным тестированием CEFR.
